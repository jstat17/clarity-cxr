# Data preparation

The code uses the public NIH ChestX-ray14 release. Download the images and the
metadata CSVs from the NIH Clinical Center and extract them so that the
dataset root contains:

```text
ChestX-ray14/
  Data_Entry_2017_v2020.csv
  BBox_List_2017.csv
  images/
    00000001_000.png
    00000001_001.png
    ...
  train_val_list.txt
  test_list.txt
```

`CLARITY_DATA_ROOT` points at the directory that contains `ChestX-ray14/`, or
pass `--data-root`. `--images_path` (or `-img`) can point directly at an image directory.

## Official NIH split

`train_val_list.txt` and `test_list.txt` are read from the dataset root and
used by `--split official` and by the classification evaluation's test split.
No split list is redistributed with this repository.

## Paper split manifest

The paper's historical classification and localization splits are supplied by
the user. Point `--splits-dir` at a directory containing:

```text
classification_train_list_70.txt
classification_val_list_70.txt
localization_val_list.txt
localization_test_list.txt
```

The loader validates patient disjointness and the historical record counts
(75,697 / 10,826 / 442 / 438) with `--verify-splits`. The lists are not
generated by this repository.

## Anatomical segmentation masks

Combined-loss training and the localization evaluation need anatomical-region masks.
Install the `data` extra and run:

```bash
uv run clarity-segment <images-dir> <segmentations-dir>
```

This writes one compressed `*.pk.xz` mask file per image. To build the fast
`.npz` cache used by the loader:

```bash
uv run clarity-prepare \
  -seg <segmentations-dir> \
  -out <cache-root> \
  -s 224 512 \
  --workers 8
```

The cache is content-addressed by the source mask hash, and `--verify` checks
existing entries without rewriting them.

## Teacher labels (distillation only)

Teacher-label generation uses `clarity-predict`:

```bash
uv run clarity-predict convnextv2 b <teacher-checkpoint.pth> \
  --images_path <images-dir> -ds chestxray14 --data-root <data-root> \
  -n 100 -sn 0
```

Pass the generated directory through `--precomputed_teacher_labels_path` when
training a distilled student. Teacher checkpoints and labels are not
distributed.

## RSNA Pneumonia and VinDr-CXR

The transfer study reads two further datasets (`clarity.data.rsna`,
`clarity.data.vindr`). Their layout, the expected PNG directories and the
